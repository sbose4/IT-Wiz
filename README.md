# IT-Wiz

IT-Wiz is a website developed for a CMIT Solutions branch as part of my work as an IT Systems Support Technician. The website was designed to provide a professional online presence for the branch and make its IT services and information easily accessible to customers.

## Features

- Responsive website design
- Information about available IT services
- User-friendly navigation
- Contact and business information
- Optimized layout for desktop and mobile devices

## Technologies

- HTML
- CSS
- JavaScript

## About the Project

I developed this project as part of my work at CMIT Solutions. The project gave me experience designing and developing a website based on the needs of a real business while focusing on usability, responsiveness, and maintainable code.
